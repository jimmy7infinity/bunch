I have designed this website using Figma, I will describe it to you in as much detail as possible. Be considerate of the fact that I’ve built this using a 1440px x 1024px aspect ration layout. It’s important that You are considerate of this info since I will often describe pixels, you must sometimes reinterpret these as relative/percentages, to ensure our website is responsive, adjusts attractively to different screen sizes but still appears like I have designed on the 1440px. This is particularly important because this website will use a snapping scroll, not a free scroll. So each section occupies the entire page, and when a user scrolls it snaps to the section above or below that they are scrolling to. Please also make sure to make the website mobile compatible.The website is neumorphic, just like the bunch extension and follows very similar design language. You can use it as a reference and even steal elements from it for anything we create beyond my basic design.Rules and elements
