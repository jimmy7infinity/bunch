**This is pure grant gold: education + engagement + zero risk.**

### 6.1 Contest Mechanics

**How It Works:**
1. User browses markets in Bunch
2. User picks YES or NO (no money, pure prediction)
3. Pick is stored off-chain in Bunch database
4. When market resolves, pick is compared to outcome
5. Correct picks earn XP, inventory, leaderboard position

**No Money Involved:**
• Zero custody risk
• Zero compliance overhead
• Pure skill game
• Perfect for new user onboarding
• Can be done from anywhere (no wallet needed initially)

## MODULE 7 — XP SYSTEM (ANTI-SPAM DESIGN)

**Key Insight: XP should reward quality and contribution, not spam.**

### 7.1 XP Sources (Reputation-Based)

**Social Quality:**
• Reactions received on your messages (+5 per unique reaction)
• Replies received (+3 per thoughtful reply)
• Upvotes on messages (+10 per upvote)
• Message thread initiations that get engagement
• Helpful tag from mods (+50)

**Trading Activity:**
• Correct market predictions in contests (+20-100 based on difficulty)
• Win streaks (multiplier: 1.5x per consecutive win, max 3x)
• Active position holding (+5/day per market)
• Early market participation (+15 for first 100 participants)
• Diamond hands bonus (+50 for 30+ day holds)

**Social Proof:**
• Being copied (someone follows your pick) (+25)
• Being followed (+10 per new follower)
• Leaderboard placement (top 100 weekly: +100-500)
• Contest victories (+200-1000)

**Market Discovery:**
• First to chat in new market (+30)
• Sharing markets that gain traction (+20)
• Creating valuable market discussions

### 7.2 Anti-Spam Safeguards

**What DOESN'T Earn XP:**
• Sending messages (quantity ≠ reward)
• Simple reactions
• Self-promotion
• Spam detected by mods (negative XP)
• Low-effort content flagged by community

**Rate Limits:**
• Max XP per day: 500 (prevents grinding)
• Max XP per source per day (prevents gaming single mechanic)
• Diminishing returns on repetitive actions

**Quality Filters:**
• Messages must be >10 characters to earn reaction XP
• Replies must be from unique users to count
• Streaks require minimum time between picks (no rapid-fire gaming)

### 7.3 XP → Rank Progression

**Thresholds (Example):**
• RECRUIT → VETERAN: 1,000 XP
• VETERAN → CAPTAIN: 3,000 XP
• CAPTAIN → CHAMP: 7,000 XP
• CHAMP → HERO: 15,000 XP
• HERO → TITAN: 30,000 XP
• TITAN → ICON: 60,000 XP
• ICON → LEGEND: 100,000 XP
• LEGEND → LEGEND+: 200,000 XP (seasonal reset)

**Seasonal Reset:**
• XP resets each season (3 months)
• Ranks preserved as "legacy" on profile
• Creates urgency and fresh competition
• Prevents stagnation at top ranks

**Why This Matters:**
→ Rewards genuine contribution, not spam
→ Creates quality-driven community
→ Aligns incentives with Polymarket goals (engagement → trading)
→ Prevents gaming and exploitation
→ Maintains long-term balance and fairness
