📸 Bunch Chrome Extension - Screenshot Guide

Quick Start

You need 5 screenshots at exactly 1280x800 pixels (or 640x400)

Time needed: 10 minutes

Screenshot 1: Login Screen (1280x800)

What to Capture: Login/Welcome Screen

Your Login Screen Here
Show: Wallet Connect + Twitter Auth

How to Take This Screenshot:

  1. Open Chrome and install your extension (load unpacked from frontend/dist)
  2. Click extension icon to open side panel
  3. Make sure you're logged OUT to show the login screen
  4. Open Chrome DevTools (F12 or Cmd+Option+I)
  5. Click "Toggle device toolbar" or press Cmd+Shift+M
  6. Set dimensions to: 1280 x 800
  7. Capture screenshot (DevTools > ... > Capture screenshot)
  8. Save as screenshot-1-login.png

Make sure visible: Bunch logo, "Connect with Twitter" button, wallet connect option

Alternative: Use Regular Screenshot Tool

  1. Open your extension in Chrome
  2. Use any screenshot tool (macOS: Cmd+Shift+4, Windows: Snipping Tool)
  3. Capture the extension interface
  4. Open in any image editor (Preview, Paint, Photoshop, etc.)
  5. Crop/resize to exactly 1280 x 800 pixels
  6. Export as PNG

✅ Quality Checklist (Before Submitting)

  • ✅ All screenshots are exactly 1280x800 pixels
  • ✅ Images are PNG format (not JPG)
  • ✅ Text is readable and crisp (not blurry)
  • ✅ Extension interface is clearly visible
  • ✅ No browser chrome visible (just extension UI)
  • ✅ Different features shown in each screenshot
  • ✅ Screenshots show actual functionality (not mockups)
